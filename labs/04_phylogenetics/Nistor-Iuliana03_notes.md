## Reflection
A distance matrix only shows pairwise differences numerically.  
A phylogenetic tree adds **evolutionary structure**:

- Which sequences share a recent common ancestor  
- How sequences cluster into clades  
- Divergence order between lineages  
- A visual interpretation of relationships  

Thus, the tree transforms raw distances into a meaningful evolutionary story.
